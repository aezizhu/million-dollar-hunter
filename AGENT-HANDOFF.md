# Agent Handoff Protocol

## When Completing a Task
- Update relevant docs and specifications.
- Validate OpenAPI (syntax) and include validation result link or note.
- Summarize changes and next steps.

## Required Artifacts
- Updated file list with brief change notes.
- Links to PR(s) and any preview environments.
- Test summaries (if applicable), including perf baselines.

## Notification
- Assign the next agent/owner in the PR or task tracker.
- Post a short status with what changed, why, and what decision is needed next.

## SLA
- Respond to handoff notifications within 1 hour during active cycles.
